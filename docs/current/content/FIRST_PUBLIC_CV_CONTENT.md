## Projekty

### Haiku Cosmos

Autorska kontemplacyjna gra-system rozwijana od 01/2026. Łączy mechaniki gry, generatywny kosmos, system kart, warstwę poetycką i narzędzia diagnostyczne. Publiczne demo i repozytorium są dostępne.

### DIG Engine

Lokalny system eksploracji muzyki i pracy z dużymi bibliotekami danych, rozwijany od 03/2026. Łączy integracje Spotify, Last.fm i Discogs, lokalną bazę SQLite/FTS5, system DNA decyzji użytkownika oraz Workflow Composer. Pełne repozytorium pozostaje prywatne; publiczny GIF jest demonstracją.

### Interactive AI Portfolio

Interaktywna przestrzeń Three.js z 2026 roku, służąca jako środowisko prezentacyjne dla projektów, w tym Haiku Cosmos i DIG Engine. Publiczne demo i repozytorium są dostępne.
